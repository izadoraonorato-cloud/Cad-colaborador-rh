# Sistema de Cadastro e bonificacão de novos colaboradores 
## Descrição 

Sistema responsável pelo cadastro de novos colaboradores. No sistema, devera ser informado o nome do colaborador e seu respectivo salário. O sistema deverá retornar uma mensagem de boas vindas dizendo ao colaborador o seu salário base juntamento com o seu salário bonificado com 15%
 
 ## Funcionalidades

 O sistema tem como objetivo reconhecer a chegada de novos profissionais à empresa, proporcionando uma experiência positiva desde o primeiro cadastro. A bonificação busca incentivar o colaborador e contribuir para sua motivação e permanência na empresa.
